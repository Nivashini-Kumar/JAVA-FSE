# Git Hands-on Lab 5 - Repository Cleanup and Remote Synchronization

## Objective

Understand how to synchronize a local repository with a remote repository after completing development.

## Topics Covered

- Checking repository status
- Viewing available branches
- Pulling latest changes
- Pushing commits to GitHub

## Commands Practiced

```bash
git status
git branch
git pull origin main
git push origin main
```

## Learning Outcome

Successfully synchronized the local repository with the remote repository by pulling the latest updates and pushing completed work.
