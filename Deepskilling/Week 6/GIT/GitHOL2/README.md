# Git Hands-on Lab 2 - Using .gitignore

## Objective

Learn how to ignore unwanted files and folders from being tracked by Git.

## Topics Covered

- Creating a `.gitignore` file
- Ignoring log files
- Ignoring folders
- Verifying ignored files using Git status

## Files Used

- .gitignore
- log/
- *.log

## Commands Practiced

```bash
git status
git add .
git commit -m "Added gitignore rules"
```

## Learning Outcome

Configured Git to ignore unnecessary files and folders, keeping the repository clean and preventing unwanted files from being committed.
