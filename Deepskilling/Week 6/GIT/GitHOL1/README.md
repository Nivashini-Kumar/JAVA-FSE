# Git Hands-on Lab 1 - Git Setup and Basic Commands

## Objective
Configure Git on the local machine and understand the basic workflow of creating and managing a Git repository.

## Topics Covered
- Git installation verification
- Git user configuration
- Repository initialization
- File creation and tracking
- Local commit
- Synchronizing with a remote repository

## Commands Practiced

```bash
git --version
git config --global user.name "<username>"
git config --global user.email "<email>"
git config --global --list
git init
git status
git add welcome.txt
git commit -m "Initial commit"
git pull origin main
git push origin main
```

## Files Used

- welcome.txt

## Learning Outcome

Successfully configured Git, initialized a repository, tracked a file, committed changes locally, and synchronized the repository with GitHub.
