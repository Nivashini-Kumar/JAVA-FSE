# PL SQL Programming

## Overview

This directory contains the PL/SQL programming exercises completed as part of the Cognizant Java Full Stack Engineer learning program. The exercises focus on implementing core PL/SQL concepts using practical banking-related scenarios.

## Exercises Included

### Control Structures
- Conditional statements
- Loops
- Cursor-based processing
- Decision making in PL/SQL

### Stored Procedures
- Procedure creation and execution
- Parameterized procedures
- Business logic implementation
- Database update operations
