# Library Management

## Description

This project is a simple Library Management application developed using the Spring Framework and Maven. It demonstrates the basic concepts of Spring, including dependency injection, the IoC container, XML-based bean configuration, and Spring Boot.

## Technologies Used

* Java 17
* Spring Framework
* Spring Boot
* Maven

## Features

* Spring IoC Container
* Dependency Injection
* Constructor Injection
* Setter Injection
* XML Bean Configuration
* Spring Boot Application

## How to Run

1. Clone the repository.
2. Open the project in your preferred IDE.
3. Build the project using Maven:

   ```bash
   mvn clean install
   ```
4. Run the application:

   ```bash
   mvn spring-boot:run
   ```
