# Handson 1 - Spring Data JPA Quick Example

## Objective

This handson demonstrates the basics of Spring Data JPA with Hibernate using a Country entity.

## Concepts Covered

- Difference between JPA, Hibernate and Spring Data JPA
- Spring Boot configuration with Spring Data JPA
- Entity Mapping using @Entity
- JpaRepository
- Service Layer
- Find Country by Country Code
- Add New Country
- MySQL Database Integration
